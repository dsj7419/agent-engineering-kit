# Code of conduct

We welcome contributors of different backgrounds, skill levels and tool preferences. Discuss ideas and evidence respectfully. Give constructive feedback, acknowledge mistakes and respect privacy. Harassment, threats, discrimination, unwanted sexual attention, personal attacks and disclosure of private information are unacceptable.

Maintainers may moderate discussions, remove inappropriate content and restrict access for repeated or serious violations. Decisions should be proportional and protect affected participants. Report concerns privately to a maintainer using their published GitHub contact method; if none is available, ask for a private reporting channel without sharing sensitive details. Use GitHub's abuse reporting features if appropriate. Do not retaliate against good-faith reporters.
