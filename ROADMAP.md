# Roadmap

- **2.1:** Public-release package: documentation, community policies, non-overwriting installation, repository CI, initial example and benchmark protocol.
- **2.2:** Adaptive engineering policy, calibrated project metrics, standards crosswalk and Java cohesion example. Further stack integrations and installer upgrades remain future work.
- **2.2.1:** Public release hardening: risk-based bootstrap, clearer onboarding, release packaging validation and explicit security launch checks.
- **2.3:** Prioritize a runnable TypeScript/Next.js example with boundary and behavior tests; follow with a Go package-oriented example. Add reproducible controlled experiments across agents, versions, tasks and budgets. Publish raw sanitized evidence, negative results and limitations.
- **3.0:** Evidence-backed standards and broader production validation; scope and timing depend on results and community feedback.

This roadmap is directional, not a release-date commitment. Benchmark results and adoption are not claimed before measurement.
